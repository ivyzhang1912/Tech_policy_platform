# 科政鸣：科技政策摘要与个性化推送小程序

面向企业和科研人员的科技政策服务微信小程序：对政策原文生成摘要，并根据用户浏览记录进行个性化推送。项目获 2023 年中国大学生计算机设计大赛江苏省二等奖。

## 系统流程

1. **文本清洗**：按规则去除政策正文中的网页与公众号噪音文本（如页面提示、订阅信息、阅读量等）。
2. **摘要生成**：按句切分正文并去除条款序号，转换为摘要模型输入；模型输出汇总回政策表。
3. **关键词提取**：基于自建词表与停用词表进行逆向最大匹配分词，计算 TF-IDF，每条政策保留权重最高的 10 个关键词。
4. **个性化推送**：将用户浏览过的政策关键词及权重累加为用户偏好画像（保留前 10 个关键词），据此对全部政策打分，推送得分最高的 20 条。
5. **小程序前端**：热门政策、按类型与地区筛选的政策库、搜索、收藏、浏览记录、个性化推送。

## 仓库结构

| 目录 | 内容 |
|---|---|
| `1_数据处理` | 文本清洗、分句、去序号、摘要汇总、TF-IDF 关键词提取 |
| `2_后端服务_Flask` | 登录、政策查询、收藏、浏览记录与推送接口（Flask + MySQL） |
| `3_微信小程序` | 小程序前端 |
| `4_演示视频` | 小程序操作演示 |

## 环境与运行

- 后端：Python 3，依赖见 `2_后端服务_Flask/requirements.txt`；需创建 MySQL 数据库 `tech_policy`；数据库密码与小程序 AppSecret 通过环境变量 `DB_PASSWORD`、`WX_APPSECRET` 配置
- 前端：在 `3_微信小程序` 目录执行 `npm install` 安装 `tdesign-miniprogram` 与 `dayjs`，再在微信开发者工具中构建 npm；接口地址需改为实际后端地址
- 数据处理脚本中的文件路径为原始开发环境路径，运行前需按本地目录修改
